# dsh-videocall

**局域网里的视频通话插件，挂在 DeepSeek Harness 上。**

手机打开一个链接，就能和自己的 DSH 助手视频：**助手那边出镜是皮套**（VTube Studio → OBS → 虚拟摄像头），**你这边是真实摄像头**。助手能按档位"看你"——低画质看轮廓，需要时拉一帧高清。

零驱动、零端口暴露：插件自己起一个只绑本机的服务，不碰 DSH 主端口。

---

## 它能做到什么

| 能力 | 状态 |
|---|---|
| 手机 ↔ 电脑 双向视频 + 音频 | ✅ 同一网络下实测通过 |
| 助手出镜 = 皮套（VTS → OBS 虚拟摄像头） | ✅ 实测 |
| 助手出声 = Web Audio 造音轨（**不用虚拟声卡**） | ✅ 实测 |
| 助手"看"你 = 页面抽帧回传 → 图片附件 | ✅ 实测 |
| 常驻房（链接重启不丢，手机可存书签） | ✅ 实测 |
| 网络档案（换网络免重配） | ✅ 实测 |
| 内嵌控制面板（侧栏入口） | ✅ 实测 |
| 首次自动生成证书 | ✅ 实测 |
| 公网隧道（Cloudflare） | ⚠️ 代码完整，能否接通取决于你的网络 |
| 自建隧道（frp 等） | ✅ 协议层兼容，填地址即可 |

---

## 它做不到什么（先说清楚）

- **只在 Windows 上完整可用**：OBS 虚拟摄像头是 DirectShow 组件，皮套那一路依赖它
- **公网不是开箱即用**：需要你自己有一条能连出去的隧道（见下文）
- **同一校园网可能连不上**：很多学校开了客户端隔离，设备之间禁止互访，软件层无解
- **对称 NAT 下 P2P 可能失败**：需要 TURN，本版只留了配置位

## 安装

```bash
dsh plugin --profile desktop add dsh-videocall
```

或者在 DSH 的 **Plugins → Add plugin** 里选本地目录。

装完**重启一次 DSH**（Client 端的侧栏入口需要重启才会挂上）。

## 三步上手

### 第一步：确认皮套能进摄像头

装好 **OBS Studio**（30+ 版本自带虚拟摄像头）和 **VTube Studio**。

1. 第一次用 OBS 前，先注册虚拟摄像头驱动（管理员）：
   `OBS安装目录\core\win-dshow\data\virtualcam-install.bat`
2. 打开 OBS，场景里加一个「窗口采集」或「游戏采集」抓 VTS 窗口
3. 点 OBS 的「启动虚拟摄像机」

验证：随便打开一个网页版的摄像头测试页，摄像头下拉里应该能看到 `OBS Virtual Camera`。

### 第二步：开面板，拿链接

点左侧栏的 **「视频通话」** 图标，进入面板。

面板里的「常驻房链接」就是你要发给手机的地址。点「复制链接」。

### 第三步：手机打开

1. 手机连上**和电脑同一个 WiFi**
2. 打开那条链接
3. 证书警告 → 点「高级 → 继续前往」（自签证书，正常现象）
4. 点「授权设备」，允许摄像头和麦克风
5. 点「开始通话」

电脑这边同样打开面板里的「本机打开」，选 `OBS Virtual Camera`，点「开始通话」。

**两边都 connected 之后，你在手机上就能看到皮套，我这边就能看到你。**

## 换网络怎么办

面板的「网络档案」会记住你去过的网络。

换到一个新网络时：

1. 打开面板，看「当前 IP」变了没
2. 变了 → 在档案里加一条（起个名字 + 填那个 IP）→ 添加
3. 点「更新证书」→ 等几秒
4. 重载插件
5. 复制新的常驻房链接给手机

**之后每次回到这个网络，不用再做第 3、4 步**——证书里已经有这个 IP 了。

> 注意：自签证书绑的是 IP 和域名。如果你用域名访问（比如 frp 的域名），证书里没有那个域名，浏览器会报"证书与域名不符"。

## 公网（进阶，可选）

插件预留了三条路，**都不需要改代码**：

| 路 | 做法 | 前提 |
|---|---|---|
| **Cloudflare Quick Tunnel** | 面板「激活」按钮 / `videocall_tunnel start` | 你的网络能连到 Cloudflare（很多国内网络不行，先用 `curl -k https://1.1.1.1` 之类的测一下） |
| **自建 frp** | 起 frp 客户端 → 面板填「外部地址」→ 重载 | 一台有公网 IP 的服务器 |
| 花生壳 / natapp | 同上 | 对应服务账号 |

**frp 示例**（本机 frpc.ini）：

```ini
[common]
server_addr = 你的服务器IP
server_port = 7000

[dsh-videocall]
type = tcp
local_ip = 127.0.0.1
local_port = 8790
remote_port = 6000
```

然后在面板「外部地址」里填 `https://你的服务器IP:6000`，重载插件。链接会自动变成这个地址，Host 白名单也会放行它。

## 面板里有什么

| 区块 | 内容 |
|---|---|
| 当前状态 | 监听地址、HTTPS 是否开、局域网模式、对外地址、隧道状态、房间与对端、最近一帧 |
| 常驻房链接 | 完整链接 + 复制 / 本机打开 |
| 网络档案 | 当前 IP、匹配到的档案、档案列表（可增删）、更新证书 |
| 一键就位 | 激活（起隧道）/ 停用（切断）/ 刷新状态 |
| 路径设置 | 外部地址、cloudflared 路径、证书 PFX、证书口令、皮套摄像头关键字、OBS/VTS 路径 |

所有管理操作**只允许本机访问**——面板服务端会校验来源地址，局域网里的别人和公网都调不动。

## 工具

| 工具 | 干什么 |
|---|---|
| `videocall_room` | 返回常驻房链接（不传 label）；传 label 则开临时房 |
| `videocall_status` | 端口、房间、对端在线、最近一帧 |
| `videocall_look` | 把最新一帧存成图片附件交给模型 |
| `videocall_netcheck` | 列出本机所有 IP、监听地址、是否 HTTPS、建议手机打开哪个地址、隧道状态 |
| `videocall_tunnel` | `start` / `stop` / `status` 公网隧道阀门 |
| `videocall_ping` | 往通话页推一行提示字 |
| `videocall_stop` | 关服务、清房间 |

## 安全

默认就位的护栏：

- **只绑回环**或局域网，公网默认摸不到
- **Host 校验**：Host 不是回环/本机网卡/`publicBaseUrl` 的域 → `421`（挡 DNS rebinding）
- **Origin 校验**：带 Origin 的请求必须同源或白名单 → 否则 `403`（挡 CSRF）
- **join 限流**：每 IP 每分钟上限，挡令牌爆破
- **令牌** 128 位随机 + 定长比较
- **请求体上限**：JSON 1 MB、帧 4 MB
- **静态文件白名单** + 路径穿越拦截
- **管理端点只认本机**
- 日志只打房号前 8 位，不打令牌

已知弱点（不藏）：

- 令牌在 URL 里，会进浏览器历史。常驻房默认 7 天有效期
- 自签证书需要手机手动接受一次
- `turnCredential` 是本机明文配置

## 排障

| 现象 | 先查什么 |
|---|---|
| 手机打不开链接 | `videocall_netcheck` 看 IP 对不对；手机是否同一网络；证书是否含这个 IP |
| 页面开了但黑屏 | 电脑端日志有没有「收到远端轨道: video」；手机有没有"画面源已开" |
| 手机拿不到摄像头 | iOS 需要用户手势触发；确认点了「授权设备」而不是自动流程 |
| 只有声音没画面 | 通常是手机端没发视频——检查下拉是不是停在「不送画面」 |
| 摄像头被占用 | VTS 会独占物理摄像头；先让通话占住，再启动 VTS |
| 隧道起不来 | `videocall_tunnel status` 看 `lastError`；国内网络到 Cloudflare 常不通 |

```
├─ index.js            Host 入口：服务、常驻房、隧道、面板 API、工具

```
